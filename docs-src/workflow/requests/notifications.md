# Notifications

> 📷 Screenshot needed: the **Notifications** page, with unread request notifications and one system notification showing **In progress**

Notifications tell you when something happens that concerns you: a request reaches you, changes status, or a long task you started in the background finishes. They appear under the bell in the top bar as they arrive, and on the **Notifications** page.

## Where notifications come from

| Kind | What triggers it |
|---|---|
| Request notifications | Activities set up on the process's steps, for example when a request reaches your step, is approved, held or completed. Which events notify whom is decided by the administrator. See [Step activities](../process-design/step-activities.md). |
| System notifications | Work you started that runs in the background: creating requests from Excel, exports and scheduled reports, importing or copying processes, creating users in bulk, directory sync, and solving incidents for a whole process. |

Request notifications show the **Request ID**, **Request Code**, **Process Name**, the request's status and when it was sent. System notifications show their progress, for example **In progress**, **Completed** or **Completed with errors**.

Emails and SMS messages are sent by the same activities, separately from these notifications. See [Activity logs](../process-design/activity-logs.md).

## Read your notifications

1. Select the bell in the top bar.
2. Select **See All Notifications** to open the **Notifications** page.
3. Select a notification to see its details.
4. To open the request it's about, select **View Request**.

To see only what you haven't read, select **Unread**. To mark one as read without opening it, use **Mark as read** on it. To clear the badge on the bell, select **Mark all as read**.
