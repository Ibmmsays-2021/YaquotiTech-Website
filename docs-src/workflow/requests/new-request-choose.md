# Choose a service

> 📷 Screenshot needed: **New Request**, the process cards of one sub category, with one card **Held** and greyed out

To raise a request, you first pick the service you need from the catalog. The catalog has three levels: a category (for example, *Human Resources*), a sub category (*Leave*) and a process (*Annual Leave Request*). Administrators build it in the [service catalog](../process-design/service-catalog.md).

You see only the processes you're allowed to request: those with one of your [user groups](../process-design/user-groups.md). Categories and sub categories with nothing you can request don't appear.

To open the catalog, select **New Request** in the top menu.

## Pick a process

1. Select a category.
2. Select a sub category.
3. Select the process.

The request form opens. See [Submit a request](new-request-submit.md).

If you know the process name, type it in the box at the top of **New Request** and select it from the list. The list covers every process you can request, so you skip the category and sub category.

Each process card shows:

| On the card | What it means |
|---|---|
| **SLA Duration** | The total time the steps are planned to take. See [Request deadlines and escalation](request-sla.md). |
| **Step Count** | How many approval steps the request goes through. |
| **Held** | The process is temporarily out of use. **From** and **To** show the hold dates, when set. |

> ℹ️ **A held process is listed but can't be opened.** Its card is greyed out until an administrator releases it. See [Hold, release, move or copy a process](../process-design/process-lifecycle.md).

To read a category, sub category or process description before opening it, select the information icon on its card.
