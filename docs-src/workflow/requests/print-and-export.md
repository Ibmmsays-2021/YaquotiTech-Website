# Print or export a request

> 📷 Screenshot needed: the **Request Data** page, with **Print options** open and some sections ticked

You can print a request or save it as a PDF, either as a full report of its data or as a formatted document built from the process's print template, for example a signed letter or certificate.

Open the request and select **Print / Export**, then choose:

| Option | What you get |
|---|---|
| **Request Data** | A report of the request that you put together from the sections you choose. |
| **Request Template** | The request's data laid out in the process's print template. |

## Print the request data

1. Select **Print / Export** > **Request Data**.
2. Under **Print options**, tick the sections to include.
3. Optionally, change how the report looks with the options below.
4. Select **Print**, or **Save as PDF**.

The sections are **Request Summary**, **Requester Information**, **Request Details** (the data entered at each step), **Step Details**, **Steps Timeline**, **History**, **Time Analysis (OLA)** and **Conversations**.

| Option | What it does |
|---|---|
| **Show empty fields** | Includes fields that were left empty. |
| **Include email / SMS bodies** | Includes the full text of emails and SMS messages in **Conversations**. |
| **Start each section on a new page** | Puts a page break before each section. |

## Print the request template

1. Select **Print / Export** > **Request Template**.
2. Select **Print**, or open the export menu and select **Preview** or **Export** to save it as a PDF.

The template is designed by the process's administrator. See [Print templates](../process-design/process-templates.md).

The printed template carries a QR code. Scanning it opens the document verification page, where anyone can check that the document is genuine from its **Request Code**. See [Complete your account](../administration/complete-your-data.md).
