# Hold a request for correction

> 📷 Screenshot needed: the hold window, with two fields selected under **Select this field**, a **Comment** on each, and a grid showing **Or select the rows to correct**

When something entered at the previous step is wrong or missing, the approver can send the request back for correction instead of deciding on it. The person who filled in that step corrects only the fields the approver chose, and the request comes straight back.

Only steps that allow holding offer it. See [Approver actions](../process-design/step-approver-actions.md).

## Hold the request

You need to have picked the step. See [Pick up and assign requests](pick-up-and-assign.md).

1. Open the request and go to the **Details** tab.
2. On the previous step, select **Hold For Correction**.
3. Select the fields to correct and add a **Comment** to each, saying what's wrong.
4. Select **Confirm Hold**.
5. If the **Request Due Date** window opens, select **Yes** or **No**.

The request goes to the person who filled in that step: the requester for the request form, or the approver who decided the step. They receive an email, and the request shows under **Make An Update** in their [requests list](requests-list.md). In yours, it shows under **Held By You**.

Only the step just before yours can be held. Select at least one field, or the hold isn't saved.

For a grid, you choose what can change:

| Option | What the other person can do |
|---|---|
| **Select to let new rows be added** | Add new rows to the grid. |
| **Or select the rows to correct** | Edit only the rows you select. Other rows stay as they are. |

> ℹ️ **The deadline pauses while the request is on hold.** When the correction comes back, the request's due date and your step's due date move later by the time it was on hold. See [Request deadlines and escalation](request-sla.md).

## Correct a held request

When a request is held for you, it shows under **Make An Update**.

1. Open the request. The step is marked **Held**.
2. Read the comment on each field, and correct the fields marked with *. All of them must be updated.
3. Select **Update Hold**.

Only the fields the approver selected can be changed. The approver receives an email that the request is updated.

## Check the correction

After the update, the step is back with you, still picked, under **Make An Action**. Review the corrected fields and [decide on the step](decide-on-a-step.md) as usual.

If the correction still isn't right, hold the request again the same way.
