# Customer portal: track a request

> 📷 Screenshot needed: the customer portal's **Request Inquiry** page, showing one result card with its **Current Step**, **Due Date** and **Progress**, and the **Cancel** button

Customers use **Request Inquiry** to see where a request stands: which step it's at, how far along it is, and the notes the approvers left for them.

To open it, select **Inquiry** in the portal menu, or **Track a request** on the portal home page. See [Customer portal: submit a request](customer-portal-new-request.md).

## Find a request

1. Under **Search By**, choose how to search:
   - **Request**: enter the **Request Id** or the **Request Code**.
   - **Requester**: lists every request you raised. You need to be signed in; if you aren't, select **Sign-in**.
2. Select **Search**.

Each result shows the request's **Id**, **Process**, **Current Step**, **Created At**, **Due Date** and **Progress**, the number of steps completed out of the total.

## Read a request's details

Select a result to open its **Request Details**.

| Part | What it shows |
|---|---|
| Steps | Each step of the request, and whether it's done, in progress or cancelled. |
| **Customer Notes** | The notes approvers wrote for you when they approved or cancelled a step. See [Approve or decline a step](decide-on-a-step.md). |
| **Submitted Data** | The form you filled in. You need to be signed in to see it. |

## Cancel your request

While signed in, you can cancel a request that's still in progress, when its current step allows it.

1. Find the request.
2. Select **Cancel** on its card and confirm.

The request ends with the status **Cancelled | Requester**. See [Cancel or reopen a request](cancel-and-reopen.md).
