# Saved and scheduled reports

> 📷 Screenshot needed: **Configuration** > **Reporting** > **Saved Reports**, **Folders** tab, showing several folders

Saved reports keep the reports you built so you can run them again in one click. A schedule runs a saved report for you, once or on a regular basis, and delivers the file by email or to a network folder.

To use saved and scheduled reports, your system role needs the **Reports** permissions. See [System roles](system-roles.md).

Both are under **Configuration** > **Reporting**: **Saved Reports** and **Scheduled Reports**.

## Organize reports in folders

On the **Folders** tab of **Saved Reports**, select **New** to create a folder. Give it a **Folder Name** of 3 to 50 characters and, optionally, a **Description**.

To rename a folder, select **Edit** on it.

> ⚠️ **Deleting a folder also deletes every report in it, and can't be undone.** Check what it contains first.

## Run or delete a saved report

Open the folder and select the report to run it with its saved columns and filters. To remove it, select **Delete** and confirm. Deleting can't be undone.

To create a report, see [Report builder](report-builder.md).

## Schedule a report

1. Open **Scheduled Reports**.
2. Enter a **Name**, choose the **Report** and its **Format**.
3. Under **Select Schedule Type**, choose **Generate Once**, **Daily Report**, **Weekly Report** or **Monthly Report**, and set the start date and time. For weekly reports, tick the days.
4. Choose where the file goes: an email, with the receiver's address, a **Subject** and a **Message**, or a **Schedule Location** on your network.
5. Select **Save**.

Use **PDF** or **Excel**. Other formats can be chosen, but the report isn't generated in them.

> ⚠️ **A scheduled file may contain personal or confidential data.** Send it only to people allowed to see it, and use a network folder that only authorized people can open.

The **Schedules** tab of **Saved Reports** lists every schedule with its type, format and receiver.
